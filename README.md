# 门店号码关系图

这是基于 [Ckxkx/account-atlas](https://github.com/Ckxkx/account-atlas) `c5460ef` 的非官方网页版。原有卡包和关系图共用同一份记录。在手机号卡片填写使用门店、主副卡、套餐、宽带和工作机后，可在原关系图按门店筛选。点一次号码高亮关联，再点一次打开详情。

## 本地运行

在仓库根目录执行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

打开[账号星图](http://127.0.0.1:8000/)。首次打开为空白，可以在卡包中添加手机号、邮箱和平台账号。

## 静态部署与数据

仓库页面由静态 HTML、CSS 和 JavaScript 构成，无须构建。静态托管入口为 `index.html`。需要同时上传 `icons/` 和根目录前端资源，`preview/index.html` 负责将旧书签重定向到关系图。

记录保存在当前浏览器中，支持 JSON 备份。门店与号码字段跟随号码卡片一起备份和加密同步。站点源代码内没有预置台账。

打开「更多 → 批量导入」选择 Atlas JSON 文件。确认前会显示新增和补全的数量。合并保留已有字段，也可以在预览中选择替换本机记录并再次确认。本机导入需要先关闭加密同步。
